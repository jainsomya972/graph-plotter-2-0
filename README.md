### Installation Steps

1. Clone the repository
2. Install JDK 21, Node 22 and Maven
3. install maven dependencies - `mvn clean install`
4. Run the Spring boot server - `mvn spring-boot:run`
5. Frontend would be available at - `localhost:8080`
6. If you would like to create a jar for the application:
   1. use - `mvn clean project`
   2. then run the jar using `java -jar <jar name>`
